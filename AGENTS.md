# Mall-E App – Agent Guidelines

This repo is an **Expo / React Native** mobile app (Mall-E). When writing or refactoring React Native or Expo code, follow the guidelines in:

- **.agents/react-native-skills/AGENTS.md** – full best-practice rules and examples (lists, animations, UI, state, rendering, etc.)
- **.agents/react-native-skills/SKILL.md** – quick reference and priority summary

These files are synced from [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills). To update them, run `npm run update:agent-skills` (see README).
